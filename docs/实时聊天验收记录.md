## 二、关键复现步骤

1. 登录：`POST /api/v1/auth/verification-codes`（`purpose=EMAIL_LOGIN`）→ Mailpit 取 6 位码 → `POST /api/v1/auth/login`（`login_type=EMAIL_CODE`）。
2. 票据：`POST /api/v1/chat/ws-ticket` → `{ticket, expiresIn, wsUrl}`，有效期 60s。
3. 连接：`ws://localhost:8080/ws/chat?ticket=...`；前端经 Vite 代理使用 `ws://localhost:5173/ws/chat?ticket=...`。
4. 提问：发送 `chat.send`（`requestId` 与 `clientMessageId` 相同，`conversationId/kbId` 可为 null）。
5. 停止：对 `ack.streamId` 发送 `chat.cancel`，等待 `done{finishReason:"cancelled"}`。
6. 补发：重连后按 `lastSequence` 调 `/chat/streams/{streamId}/events`。
7. 幂等核对 SQL：

```sql
SELECT COUNT(*) FROM chat_message
WHERE user_id = 4 AND client_message_id = '<本次UUID>'; -- 结果为 1

SELECT COUNT(*) FROM (
  SELECT client_message_id FROM chat_message
  WHERE client_message_id IS NOT NULL
  GROUP BY conversation_id, user_id, client_message_id
  HAVING COUNT(*) > 1
) t; -- 结果为 0
```

8. Nginx 转发复验（本机临时容器，验证后已删除）：

```powershell
docker run -d --name kaoyan-nginx-test -p 8088:80 `
```

## 三、遗留与注意事项

1. `deploy/.env` 中 `LLM_API_KEY`、`EMBEDDING_API_KEY` 仍是占位值。本次用系统环境变量 `LLM_API_KEY=$DASHSCOPE_API_KEY`、`LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1`、`LLM_MODEL=qwen-plus` 启动，未修改仓库文件。
2. `EMBEDDING_API_KEY` 为空导致知识库检索降级。已用系统环境变量 `DASHSCOPE_API_KEY` 直连 `POST /compatible-mode/v1/embeddings` 验证：`text-embedding-v3` 与 `text-embedding-v4` 均返回 200、批量 2 条、维度 1024（与 `EMBEDDING_DIMENSION` 一致），仅发 `model+input`（与后端客户端一致）同样返回 1024 维。随后本地启动 Milvus/etcd/MinIO，后端注入 `EMBEDDING_MODEL=text-embedding-v4`、`EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1`、`MQ_DOC_PARSE_ENABLED=false` 重启，完成端到端复验：collection `doc_chunk` 按 1024 维自动创建，文档 2 个切片入库 READY，学生提问命中 2 条 `references` 并在回答中正确引用。
3. 本机 3306 已被本地 `mysqld` 占用，`kaoyan-mysql` 容器未能启动；后端连接本机 MySQL，Flyway 正常执行。部署到干净环境时直接 `docker compose up -d` 即可。
4. 后端根路径 `GET /api/v1/health` 返回 500（未映射），请使用 `/api/v1/health/live` 与 `/api/v1/health/ready`；建议后续补根路径或更新部署文档。
5. Nginx 生产转发已用仓库配置本机复验（`nginx:1.27-alpine`，`-p 8088:80`，只读挂载 `deploy/nginx.conf`），WebSocket 升级与 `/api` 代理均正常；但 `deploy/docker-compose.yml` 中并没有 nginx 服务，与 `deploy/README.md` 中「Nginx http://localhost:8088」的描述不一致，需补 compose 服务或更正文档。另：容器内 `host.docker.internal` 会先解析到不可达的 IPv6 地址并报 `connect() failed (101)`，随后回退 IPv4 成功；干净部署时建议显式用 IPv4 或加 `resolver`。
6. DashScope 免费额度对 `qwen-turbo` 触发 `429 limit_requests`，本次改用 `qwen-plus` 通过；长期联调建议使用稳定额度或本地 mock 模型。

# 文件页验收记录

> 验收日期：2026-11-21（Asia/Shanghai）
> 范围：文件列表页、分页、下载、删除、上传任务中心与 `file:*` 权限显隐

## 集成方式

- 从 `main` 基线集成文件页、验收目录和菜单权限 3 个独有提交。
- 跳过已存在于 `main` 的 Mapper 注解和一键启动脚本提交，避免重复带入。
- 文件页复用 `features/file/file.api.ts` 与 `types.ts`，删除临时 `tempFileApi.ts`。
- 上传入口复用 `UploadTaskCenter`，保留批量、分片、重试、暂停和断点续传能力。
- `/files` 路由按列表接口的实际要求收紧为 `file:view`，上传区域单独要求 `file:upload`。
- 前端学生 Mock 与当前 STUDENT 权限矩阵同步，覆盖问答、文件和学习计划权限。

## 页面验证

使用 `VITE_USE_MOCK=true` 启动 Vite，在 Chrome 中访问 `/files`：

- 管理员和学生账号均能看到“文件”菜单并打开文件列表。
- 学生账号看不到“管理后台”菜单。
- 列表正确显示文件名、类型、大小、场景、状态和上传时间。
- 下载、删除按钮按 `file:download` / `file:delete` 权限显示。
- 选择 `acceptance.txt` 后，上传任务中心显示进度并在完成后展示“已完成”。
- 页面重新加载后无浏览器控制台错误或未捕获异常。

## 边界

本次页面验收使用文件模块 Mock，验证前端接口接线、状态机和权限显隐。真实 MySQL、MinIO 和分片上传链路仍由后端测试及部署环境联调覆盖。

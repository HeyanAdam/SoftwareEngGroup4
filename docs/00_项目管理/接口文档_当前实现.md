## 四、统一响应与错误码

```json
{ "code": 0, "message": "success", "data": ... }
```

| HTTP | code | 含义 | 前端动作 |
|---|---|---|---|
| 401 | 10001 | 未登录 / Token 失效 | 清 Token，跳登录页 |
| 401 | 10002 | 账号或密码错误 | 表单内提示 |
| 400 | 10005 | 验证码错误或过期 | 刷新图形码 |
| 409 | 10004 | 账号已存在 | 提示换一个 |
| 423 | 10003 | 账号锁定 | 提示解除时间 |
| 429 | 10010 | 触发限流 | 按 `Retry-After` 倒计时 |
| 403 | 10008 | 无接口权限 | 提示无权限，**不跳登录** |
| 403 | 10009 | 无权访问该数据 | 提示无权访问 |
| 403 | 10013 | 账号已禁用 | 清 Token，提示联系管理员 |
| 400 | 10000 | 参数校验失败 | 按字段提示 |
| 500 | 90000 | 服务器异常 | 通用错误页，附 `X-Request-Id` |

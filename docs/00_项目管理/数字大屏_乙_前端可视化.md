# 数字大屏（乙）：前端页面实施手册

> 前置条件：管理员后台登录和 `AdminLayout` 已完成。
> 目标：实现管理员运营大屏的前端页面、ECharts 图表、轮询、全屏和响应式。
> 人员定位：前端可视化负责人。

## 1. 交付范围

负责：

- `/admin/dashboard` 页面。
- KPI 卡片。
- 登录、上传、聊天三类趋势图。
- 系统状态和队列状态面板。
- 最近更新时间和手动刷新。
- 15 秒轮询和页面可见性控制。
- 全屏展示。
- 前端 mock 与构建测试。

不负责：

- 聚合 SQL。
- Redis 缓存。
- RabbitMQ 管理连接。
- 后端验收文档。

## 6. 步骤 D3：KPI 卡片

新增 `DashboardKpiCard.vue`。

四张卡片：

1. 用户：总用户、启用数、今日登录、失败登录。
2. 文件：文件数、存储总量、今日上传。
3. 内容：知识库/文档数、失败文档。
4. 对话：会话数、消息数、今日消息。

文件大小函数：

```ts
function formatBytes(value: number): string {
  if (!value || value <= 0) return '0 B'
  if (value < 1024) return `${value} B`
  if (value < 1024 ** 2) return `${(value / 1024).toFixed(1)} KB`
  if (value < 1024 ** 3) return `${(value / 1024 ** 2).toFixed(1)} MB`
  return `${(value / 1024 ** 3).toFixed(2)} GB`
}
```

## 7. 步骤 D4：趋势图

新增 `DashboardTrendChart.vue`。

Props：

```ts
{
  title: string
  dates: string[]
  values: number[]
  color?: string
}
```

要求：

- 平滑折线。
- Y 轴从 0 开始。
- Tooltip 显示日期和数量。
- 数据为空时显示“暂无趋势数据”。
- 使用 `ResizeObserver`。
- `onUnmounted` 调 `chart.dispose()`。
- 更新数据时使用 `setOption(..., { notMerge: true })`，避免残留旧系列。

三个实例：

```text
登录趋势
上传趋势
聊天消息趋势
```

## 9. 步骤 D6：加载和轮询

在 `AdminDashboardPage.vue`：

```ts
const REFRESH_MS = 15_000
const days = ref<7 | 14 | 30>(7)
const summary = ref<DashboardSummary | null>(null)
const loading = ref(false)
const lastSuccessAt = ref<Date | null>(null)
const errorMessage = ref('')
let refreshTimer: number | undefined
```

规则：

- 同一时刻只允许一个刷新请求。
- 请求失败保留旧数据。
- 错误只更新错误条，不清空全页。
- `document.visibilityState === 'visible'` 时才自动刷新。
- 页面重新可见时立即刷新一次。
- `onUnmounted` 清定时器和图表资源。

接口：

```ts
getDashboardSummary(days)
```

切换到 7/14/30 天时立即刷新。

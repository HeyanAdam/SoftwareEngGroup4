## 二、实施要点

1. **不新增依赖**：直接用 Vue `shallowRef` + `markRaw` + 动态 `import()`；组件对象不进入响应式代理。
2. **并发去重**：`load()` 在已有请求时复用同一个 Promise；重复点击、预加载与点击叠加都只发一次 chunk 请求。
3. **失败可恢复**：失败进入 `error` 状态并保留原因，`retry()` 重新发起加载；父页面不受影响，抽屉 / 弹窗 / 图表不会永久不可用。
4. **占位稳定**：`LazyGate` 用 `min-height` 固定占位（抽屉 200px、弹窗 220px、图表 336px），加载前后不产生布局跳动。
5. **预加载不越界**：只有 `hover` / `focus`「分配角色」时预加载，且要求 `canUpdate`；页面加载时不预加载任何目标组件。
6. **权限不扩大**：无 `admin:user:update` / `admin:role:update` 时按钮本就不渲染，`openRoleDrawer` / `openCreate` / `openEdit` 内再加 `if (!canUpdate.value) return` 双保险。
7. **文件页上传组件未改造**：`UploadEntry` 位于页面头部、属于首屏核心上传入口，改造会拖慢首屏操作，按文档 §6.4 判定不纳入本次范围。

## 七、已知风险

- 抽屉 / 弹窗首次打开多一次 chunk 请求（约 3 kB），在网络极差时会有短暂加载占位；已用 `hover` / `focus` 预加载抵消常见路径。
- 管理大屏首次进入需要额外拉取 483 kB 的图表 chunk（ECharts）；已保持「挂载即加载」，不会延迟到用户交互。
- 加载失败依赖显式「重试」；若 CDN 持续不可用，组件在该次会话内无法自动恢复。
- `LazyGate` 通过 `v-bind="$attrs"` 透传 props，若后续给目标组件新增与 `LazyGate` 同名的 prop（`label` / `height` / `variant` / `state`）会被外壳吃掉，需要改名。

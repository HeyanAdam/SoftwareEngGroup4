## 二、待联调时要补的端到端步骤

```powershell
# 0. 启动后端（配好 KAOYAN_ADMIN_USERNAME / KAOYAN_ADMIN_PASSWORD 后首次启动会创建管理员）
cd D:\SoftwareEngGroup4\backend
mvn spring-boot:run

# 1. 管理员登录，拿 Token
$admin = (Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth/login `
  -ContentType 'application/json' -Body '{"username":"<管理员>","password":"<密码>"}').data
$h = @{ Authorization = "Bearer $($admin.token)" }

# 2. V1：无 Token → 期望 401 + 10001
Invoke-WebRequest -Uri http://localhost:8080/api/admin/users -SkipHttpErrorCheck |
  Select-Object StatusCode, Content

# 3. V3：学生 Token 访问后台 → 期望 403 + 10008
$stu = (Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth/login `
  -ContentType 'application/json' -Body '{"username":"<学生>","password":"<密码>"}').data
Invoke-WebRequest -Uri http://localhost:8080/api/admin/users -Headers @{ Authorization = "Bearer $($stu.token)" } -SkipHttpErrorCheck |
  Select-Object StatusCode, Content

# 4. V7：解绑唯一管理员 → 期望 403 + 业务提示
Invoke-WebRequest -Method Delete -Uri "http://localhost:8080/api/admin/users/1/roles/1" -Headers $h -SkipHttpErrorCheck |
  Select-Object StatusCode, Content
```

## 二、实施结果

- 插件 `vite-plugin-compression2@2.5.4`，发布与开发依赖均基于 Vite 8，无 peer 冲突，`npm install` 无告警。
- 阈值 1024 字节，Gzip 与 Brotli 同一次构建内同时生成，原始文件保留。
- 构建耗时由 1.73s 增至 3.06s（含两种算法压缩，单次采样）。

## 五、当前阶段边界

本阶段**只完成**“构建期生成压缩产物”。以下四项均**未完成**，属于下一阶段 Nginx 任务：

- 浏览器实际收到 `Content-Encoding: gzip` / `br`。
- Nginx 启用 `gzip_static`（及 Brotli 静态模块）。
- 静态资源长期缓存头（`Cache-Control` / `ETag`）。
- 生产环境页面提速的端到端测量。

不应在 PR、Issue 或汇报中声称上述任一项已完成。

## 六、已知风险

- 构建时长增加约 1.5s；随产物增长会继续上升，Brotli 高压缩等级对 CPU 更敏感。
- 压缩产物使部署包体积增大（`.gz` + `.br` 合计约 1.17 MB），需确认镜像/制品体积上限。
- Brotli 需服务端支持（`ngx_brotli` 或等价方案），Nginx 阶段若不支持则 `.br` 文件不被使用，属于冗余文件而非故障。
